Read a graph image

Drop a graph screenshot here, or click to choose a file Reads printed data labels, phase change lines, and legend text. One panel at a time reads most reliably.
Anything you black out is destroyed before upload. Drag over the image to paint an opaque box, or switch to Crop and drag to keep only that region. The tool composes a new bitmap from what is left and sends only that, so the original never leaves this tab.

The image is sent to the model through this site's server, which holds the API key. No key is entered here and none is stored in your browser. Values land in the editor below, and every metric on this page is computed from that editor rather than by the model.

Phase data

Enter values separated by commas or spaces, in session order. Keep one unit within a graph. Where session duration varied across phases, enter a rate rather than a count, or level differences will confound behavior change with exposure time.

Trend is Theil-Sen (median of pairwise slopes) unless stated. Overlap is NAP (Parker & Vannest, 2009), the index WWC v5.0 uses for its own screens, with an exact Mann-Whitney p from the full null distribution. Dual-criteria follows Fisher, Kelley & Lomas (2003); the conservative variant shifts both criterion lines 0.25 baseline SD. Phase-count standards and the 0.85 screens are WWC Procedures and Standards Handbook v5.0 (2022), which calls that threshold "relatively arbitrary and novel". Nonoverlap indices supplement visual analysis and do not replace it.
